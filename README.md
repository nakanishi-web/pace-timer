# pace-timer

自分のペースで進める、目的選択型のWebタイマーアプリケーションです。

## 概要
「制限時間に縛られず、集中しすぎた時間（超過分）まで可視化したい」という独自のUXを実現するために開発したWebタイマーです。

## 技術スタック
- **HTML5**（セマンティックなマークアップ）
- **CSS3**（洗練されたダークトーンのスタイリング）
- **JavaScript**（タイマーのカウントアップ制御、超過タイム計算、ログ管理ロジック）

## 主な機能
- **目的選択機能**: プログラミングやデザインなど、作業内容に応じた目的を選択して計測できます。
- **自由な目標時間設定**: 任意の分数を設定し、タイマーを開始できます。
- **超過タイムの可視化**:
  - `00:00:00` からカウントアップがスタートします。
  - 目標時間に到達するとアラート（警告）が表示され、制限時間を超過した後もそのままシームレスに時間を計測し続けます。
- **作業ログの自動蓄積**: タイマーを終了（リセット）したタイミングで、選択した作業目的・完了時刻・合計計測時間が下部のログに自動で記録されます。

## 開発のこだわり
- 強制的にタイマーを止めるのではなく、ユーザーの「もう少し続けたい」という集中を妨げない設計にこだわりました。
- 保守性を考えたクリーンなコードベースと、視認性の高いUI/UXを意識して実装しています。
